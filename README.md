# 🔋 Fuzzy Logic Based Smartphone Battery Management System

## 📌 Project Overview
This project is a Python-based intelligent system that uses **fuzzy logic** to manage smartphone battery usage efficiently. It analyzes battery level, usage pattern, and time of day to suggest the most suitable power mode for better battery optimization.

The system simulates real-world AI decision-making using fuzzy logic rules.

## ⚙️ Features

- Smart battery mode prediction
- Rule-based AI system

- Visualization of fuzzy membership functions

---

## 🧠 Input Parameters
- Battery Level (0–100)
- Usage Type:
  - 0 → Idle  
  - 1 → Study  
  - 2 → Gaming  
- Time of Day (0–23)

---

## 🎯 Output
- Normal Mode  
- Power Saver Mode  
- Ultra Saver Mode
